# Useful, Not True

Derived from *Useful Not True* by Derek Sivers, the book's central argument.

## Core Principle

Sivers treats beliefs as tools rather than as claims that must be proven. The question he asks is not whether a belief is objectively, verifiably true, it is whether holding that belief right now is useful to him, whether it helps him act, stay steady, or move forward. This is deliberately uncomfortable: it means picking up a belief because it works and setting it down again when it stops working, rather than building an identity around defending it as fact.

## Framework

### Step 1: Name the belief precisely

State the exact belief you are holding onto or arguing about, in one sentence, separate from the emotion attached to it.

### Step 2: Ask the truth question and set it aside

Notice whether you are spending your energy trying to prove the belief is factually correct. Set that question aside for a moment, it is not the one that matters most here.

### Step 3: Ask the useful question directly

Ask plainly: does holding this belief help me act, stay calm, or move forward right now. Answer honestly, separate from whether you can defend it as objectively true.

### Step 4: Keep it if it is useful, regardless of certainty

If the belief is genuinely helping you function, you do not need to resolve every doubt about its literal truth before continuing to hold it for now.

### Step 5: Set it down when it stops being useful

The same belief that once helped may later start to hurt. When you notice it is no longer useful, be willing to set it down, even if you never fully proved or disproved it.

## Anti-patterns

- Defending a belief purely because it is factually defensible, even when holding it is making you worse off.
- Refusing to use a helpful belief because you cannot fully prove it is true.
- Treating every belief as permanent, instead of checking periodically whether it is still useful.
- Confusing usefulness with convenience; a belief that is comfortable but genuinely harmful is not the kind of useful this is about.

## Output shape

A short evaluation of the belief in question: what it actually is stated plainly, whether the argument has been stuck on proving it true, whether holding it is currently useful regardless of that, and a decision about whether to keep it for now or set it down.

*"Instead of asking if it's true, ask yourself if it's useful to you."* Derek Sivers.
