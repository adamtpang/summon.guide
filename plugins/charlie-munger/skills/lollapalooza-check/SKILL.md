# Lollapalooza Bias Check

Derived from *Poor Charlie's Almanack* by Charles T. Munger, edited by Peter D. Kaufman (The Psychology of Human Misjudgment).

## Core Principle

Extreme misjudgment often comes from several biases acting in the same direction. The interaction is more dangerous than any isolated tendency.

## Framework

### Step 1: Slow the environment

Remove artificial urgency, separate the decision from the presentation, and create time for independent thought.

### Step 2: Inventory active tendencies

Check incentives, authority, social proof, commitment, reciprocation, scarcity, deprival, contrast, liking, and availability.

### Step 3: Find combinations

Identify which tendencies reinforce one another and what extreme behavior their combination predicts.

### Step 4: Create independent views

Collect judgments before discussion, seek a disconfirming expert, and assign a credible dissenter.

### Step 5: Reframe the choice

Remove sunk costs, sales anchors, and identity language. Compare the decision with the best current alternative.

### Step 6: Install a circuit breaker

Set a delay, evidence threshold, spending cap, or external review proportional to the downside.

## Anti-patterns

- Naming a single bias and declaring the analysis complete.
- Treating group agreement as independent evidence.
- Letting urgency prevent a reversible pause.
- Using bias labels to insult people instead of redesigning the environment.

## Output shape

Return a bias inventory, reinforcing combinations, predicted distortion, independent check, reframed decision, and circuit breaker.
