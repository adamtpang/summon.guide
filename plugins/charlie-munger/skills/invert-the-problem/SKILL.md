# Invert the Problem

Derived from *Poor Charlie's Almanack* by Charles T. Munger, edited by Peter D. Kaufman (Talks on elementary worldly wisdom and inversion, with explicit credit to Carl Gustav Jacob Jacobi).

## Core Principle

When success has many causes, failure often has a shorter and more reliable checklist. Turn the problem backward, prevent those causes, then improve the surviving plan.

## Framework

### Step 1: Define failure precisely

Describe observable outcomes that count as failure, including slow decay and irreversible damage.

### Step 2: Build the failure recipe

List behaviors, incentives, dependencies, and assumptions that would reliably produce those outcomes.

### Step 3: Rank by severity and likelihood

Put irreversible and compounding harms first, even when their probability appears modest.

### Step 4: Install avoidances

Turn each high-priority failure cause into a constraint, guardrail, owner, or early warning signal.

### Step 5: Solve forward

With ruin paths removed, choose the simplest positive action that advances the goal.

### Step 6: Pre-mortem the result

Assume the plan failed and identify what the checklist still missed.

## Anti-patterns

- Using inversion as pessimism instead of a route to action.
- Listing vague fears that cannot become safeguards.
- Treating reversible inconvenience like irreversible ruin.
- Crediting the maxim 'invert, always invert' to Munger instead of Jacobi.

## Output shape

Return a failure definition, ranked failure recipe, avoidance checklist, positive next action, and pre-mortem gap.
