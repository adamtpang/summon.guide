# The Retained Earnings Test

Derived from *Berkshire Hathaway Shareholder Letters, 1977-2024* by Warren E. Buffett (1980, 1982, and 1984 letters, retained earnings and capital allocation).

## Core Principle

Management should retain a dollar only when it has a reasonable prospect of creating more than a dollar of long-term value after risk and opportunity cost.

## Framework

### Step 1: Inventory every use

Include maintenance, organic growth, acquisitions, debt reduction, liquidity, and distribution. Do not let a preferred project become the default.

### Step 2: Separate maintenance from growth

Fund what preserves the current franchise before claiming that the remaining spend creates new value.

### Step 3: Estimate incremental returns

Judge the next dollar, not the historical average. Include execution risk, time to payoff, and future capital needs.

### Step 4: Compare with the hurdle

Use the best available alternative and a margin of safety, not an arbitrary internal target.

### Step 5: Audit the record

Compare prior promises with actual incremental earnings, cash generation, and value creation.

### Step 6: Allocate and review

Rank uses, set a review date, and specify the evidence that stops further funding.

## Anti-patterns

- Retaining cash merely because management controls it.
- Using average company returns to justify a weak incremental project.
- Ignoring dilution, integration costs, or follow-on capital.
- Rewarding project size instead of value created per dollar.

## Output shape

Return a ranked capital-allocation table with amount, incremental return logic, time horizon, downside, confidence, and stop condition, followed by the recommended allocation.
