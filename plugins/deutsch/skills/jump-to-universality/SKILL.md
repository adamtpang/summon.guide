# The Jump to Universality

Derived from *The Beginning of Infinity* by David Deutsch (Chapter 6, The Jump to Universality (the alphabet, positional numerals, Babbage's Analytical Engine, the genetic code)).

## Core Principle

Deutsch argues that systems built to solve a narrow, specific repertoire of cases sometimes acquire, through one more small rule change, unbounded reach across an entire domain, able to handle cases their designer never anticipated. This jump is qualitatively different from ordinary incremental improvement, and historically the people who triggered it were almost never trying to achieve universality. They were solving a local problem, and the jump happened when they removed an arbitrary restriction rather than added a special case for it. Since it is a repeatable, identifiable pattern, it is worth deliberately looking for the arbitrary cap still built into your own rule.

## Framework

### Step 1: Name the current repertoire

Write down the specific, finite set of cases this tool, template, or process was actually built to handle.

### Step 2: Find the arbitrary limit

Look for the hidden cap inside the rule itself: a maximum size, a fixed list, a special case clause, a highest symbol it can represent. That cap is what keeps the system parochial.

### Step 3: State the rule without the limit

Rewrite the underlying rule as if the cap were not there, and check whether the new rule still makes sense and still does the original job.

### Step 4: Test it on a case you never intended

Apply the widened rule to a case outside the original repertoire. If it works without a new patch, you found a jump to universality. If it breaks, you found the real boundary and can decide whether to widen it further or leave it.

## Anti-patterns

- Adding a new special case for every new situation instead of asking what the general rule should be
- Assuming universality has to be designed on purpose rather than noticing it can happen as a byproduct of removing a restriction
- Treating a repertoire that has worked for every case tried so far as proof it is already universal

## Output shape

A short before and after: the old rule with its hidden cap named, the new rule with the cap removed, and one test case outside the original repertoire that the new rule now handles.
