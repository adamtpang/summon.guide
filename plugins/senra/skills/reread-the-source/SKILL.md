# Reread the Source You Already Trust

Derived from *Founders Podcast* by David Senra. Rockefeller is covered three separate times across the catalog (How Rockefeller Worked, 38 Letters John D. Rockefeller Wrote to His Son, Rockefeller's Autobiography), and Steve Jobs is covered twice (Make Something Wonderful, How Steve Jobs Kept Things Simple).

## Core Principle

Senra does not read a great founder's story once and move on. He returns to the same subject years apart, from a different angle, because the material has not changed but the problem he is bringing to it has. He has annotated books by hand with a pen and a six inch ruler, photographed the highlighted pages, and gone back to them before recording, rereading rather than reading once. The claim underneath the habit: a source dense enough to reward one careful read is usually dense enough to reward several, if you come back with a different question each time.

## Framework

### Step 1: List the sources you have already trusted once

Name the books, mentors, courses, or bodies of work that genuinely changed how you thought or acted the first time, even if that was years ago.

### Step 2: State your current problem plainly

Before searching for something new, write down the actual problem you are trying to solve right now, specifically enough that you could recognize an answer if you saw one.

### Step 3: Check an old trusted source against the new problem

Before adding a new book or a new expert to the search, go back to one source from step 1 and ask what it says about the problem in step 2. Often the first read was filtered through a different problem and missed what is relevant now.

### Step 4: Reread with a pen, not a skim

If you do return to an old source, mark what is relevant to the current problem specifically, the way you would annotate something for the first time, rather than passively skimming for what you remember.

### Step 5: Only search for something new after this check

If the reread genuinely does not answer the current problem, then look for a new source. Do not skip the reread because the new thing feels more interesting to find.

## Anti-patterns

- Buying or searching for a new book or expert every time a new problem shows up, without checking whether an old trusted source already covers it.
- Treating a source as finished once you have read it, rather than as something to revisit with a new question.
- Skimming an old source from memory instead of actually rereading it with the current problem in mind.
- Assuming the first read extracted everything a dense source had to offer.

## Output shape

A short note: which old, already-trusted source you are checking against your current problem, what it actually says that is relevant now, and whether it answers enough of the problem that a new search is unnecessary.
